# Rewrite text without inventing details

Use this when the source contains all the facts you want retained, but the writing is awkward, lengthy, repetitive, or poorly structured.

~~~text
Act as an experienced human editor.

Revise the text below for natural, idiomatic, mature English. Keep the meaning and factual scope unchanged. Write for [AUDIENCE] in a [TONE] style. The intended use is [PURPOSE].

Lead with the important point. Use direct headings when helpful. Repair awkward sentence construction, unnecessary repetition, formulaic structure, and vague language. Do not apply a mechanical list of forbidden words.

Preserve every substantive detail: names, amounts, dates, units, relationships, negations, conditions, sequence, uncertainties, qualifications, and citations. Do not invent examples, statistics, quotations, benefits, testimonials, outcomes, or new promises.

If clarity requires information the source does not provide, flag the exact missing information separately. Do not guess.

Return the complete revised text first. Then, only if needed, briefly explain any unresolved ambiguity or material wording choice.

SOURCE:
[PASTE THE ORIGINAL TEXT]
~~~

For legal, clinical, financial, technical, or public-facing claims, compare the result line by line with the source before relying on it. This prompt improves the editing process; it does not verify facts that the original source may have gotten wrong.
